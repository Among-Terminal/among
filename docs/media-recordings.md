# Recording provenance

The [overview](https://among-terminal.github.io/overview/) and
[feature guide](https://among-terminal.github.io/features/) contain the user-facing
recordings. Keep `docs/media` available for the README and release notes.

## Workflow recordings

The [silent workflow tour](media/among-terminal-overview.mp4) lasts 1 min 53 s.
It joins the reviewed feature recordings with direct cuts, retaining the recorded
shortcuts without a soundtrack or explanatory subtitles. The
[extended presentation](media/among-terminal-promo.mp4) lasts 2 min 1 s and places
the workflows on a charcoal stage. It is separate from the approved 23-second
README film.

The recordings use isolated synthetic projects and do not use personal shell
startup files. zsh, Starship, `ll`, `mc` and `htop` are demonstration tools;
Among does not install or configure them. Previews link to MP4 files because
GitHub inline playback is not assumed. Fullscreen playback helps inspect text.

The restoration recording opens four fresh shells in different directories,
then runs `ll` manually. The clips do not demonstrate the context menu, shortcut
editing or preference-storage recovery. The written site guides cover those
controls without requiring playback. These recordings show native X11 behaviour;
they do not establish support for untested platforms or assistive technologies.
